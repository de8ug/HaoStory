# Project instructions

## Current policy

HaoStory is `paused` by default. Do not start, resume or maintain capture sessions merely because another project is being developed. Use this project only when Howie explicitly asks to improve HaoStory itself or to organize/review/produce promotional material for a named project.

## Before working

1. Read `README.md`, `README.zh-CN.md`, `SKILL.md` and relevant tests.
2. Inspect the existing working tree and preserve unrelated changes.
3. Distinguish between HaoStory's supported capabilities and Howie's current opt-in operating policy.

## Privacy and publication

- All captures are local and private until separately reviewed and approved.
- Redact credentials, personal data, private repository details, server access, unpublished business information and identifiable third-party material.
- Never publish, push or upload captured assets automatically.
- Open-source examples must contain synthetic or explicitly approved data.

## Verification and documentation

- Run the relevant CLI and test coverage for behavior changes.
- Keep English and Chinese public documentation aligned when capabilities change.
- Do not describe HaoStory as active in all projects; document the paused-by-default policy clearly.
- UP2U coordination remains historical/paused and is not a dependency of this project.
